# estructuras-a-medida

Repositorio del plugin "estructuras-a-medida" (ver README.md). Motor en Python (solo biblioteca estándar); ficha.json es la única fuente de verdad de cada proyecto.

- No hay Node en la máquina: el croquis 3D es Three.js dentro de la página, generado desde Python.
- Antes de publicar una propuesta, revisarla a 400 px de ancho en el navegador integrado.
- Empaquetar con `python3 empaquetar.py`; publicar en GitHub arnaldoviera/estructuras-a-medida (público, licencia MIT).
